How one turn works

ElevenLabs handles speech. A FastAPI proxy on AWS Lambda speaks the OpenAI streaming format to ElevenLabs and runs Claude with two tools.

You speak

ElevenLabs transcribes the question and sends it to the proxy as a chat completion.

Claude decides

Haiku 5.5 says a short filler, then calls search_docs with a query it writes.

Retrieval

Titan V2 embeddings in S3 Vectors return the closest doc sections, in the caller's language when possible.

Voice answer

Answer tokens stream to the Eleven v4 voice as they arrive. Citations are logged by a hidden tool and never read aloud.
